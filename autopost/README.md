# BenGen Auto Post SP

โพสต์วิดีโอสินค้าที่เตรียมไว้ในระบบ BenGen Affiliate ขึ้น **Shopee Video** อัตโนมัติ
ผ่านการควบคุมแอป Shopee บนโทรศัพท์ Android จริง ด้วย ADB + uiautomator2 (ไม่ต้อง root)

⚠️ **Shopee ไม่มี API ให้อัปโหลดวิดีโอ** เครื่องมือนี้จึงควบคุมแอปผ่าน UI (จำลองการกด/พิมพ์
เหมือนคนใช้จริง) — แปลว่าต้อง**คาลิเบรตตำแหน่งปุ่มให้ตรงกับเครื่อง/เวอร์ชันแอปของคุณเองก่อนใช้จริง**
ทำตามขั้นตอนด้านล่างทีละข้อ

---

## สิ่งที่ต้องมี

- คอมพิวเตอร์/โน้ตบุ๊ก (host) ที่จะต่อกับโทรศัพท์ผ่านสาย USB ตอนโพสต์
- โทรศัพท์ Android ที่ลงแอป Shopee (Login ไว้แล้ว) — **ไม่ต้อง root**
- Python 3.9+ บนคอมพิวเตอร์
- สาย USB คุณภาพดี (บางสายชาร์จอย่างเดียวไม่รองรับส่งข้อมูล จะเจอปัญหาต่อไม่ติด)

---

## ขั้นตอนที่ 1 — เปิด USB Debugging บนโทรศัพท์

1. ตั้งค่า → เกี่ยวกับโทรศัพท์ → กด "หมายเลขบิลด์" (Build number) รัว 7 ครั้ง จะขึ้น "คุณเป็นนักพัฒนาแล้ว"
2. กลับไปตั้งค่า → ระบบ → ตัวเลือกสำหรับนักพัฒนา (Developer options) → เปิด **USB debugging**
3. เสียบสาย USB ต่อกับคอมพิวเตอร์ → บนจอมือถือจะมี popup ถามอนุญาต "Allow USB debugging?" → กด **Allow**

## ขั้นตอนที่ 2 — ติดตั้งเครื่องมือบนคอมพิวเตอร์

```bash
# 1) ติดตั้ง ADB (ถ้ายังไม่มี)
#    Windows: โหลด "platform-tools" จาก https://developer.android.com/tools/releases/platform-tools แล้วแตกไฟล์
#    Mac: brew install android-platform-tools
#    Linux: sudo apt install android-tools-adb

# 2) เช็คว่าคอมเห็นโทรศัพท์แล้ว (ต้องขึ้น serial number ของเครื่อง)
adb devices

# 3) ติดตั้ง Python package ที่ต้องใช้
pip install -r requirements.txt

# 4) เตรียม uiautomator2 บนโทรศัพท์ (ติดตั้ง agent app เล็กๆ ลงเครื่อง — ทำครั้งเดียว)
python -m uiautomator2 init
```

ถ้าขั้นตอนที่ 4 สำเร็จ จะมีไอคอนแอปเล็กๆ ชื่อ "ATX" หรือคล้ายกันโผล่มาในเครื่อง (เป็น agent
ของ uiautomator2 ปล่อยไว้เฉยๆ ไม่ต้องเปิดเอง)

ทดสอบว่าเชื่อมต่อสำเร็จ:

```bash
python -c "import uiautomator2 as u2; d = u2.connect(); print(d.info)"
```

ถ้าเห็นข้อมูลเครื่อง (เช่น ชื่อรุ่น, ความละเอียดจอ) แปลว่าเชื่อมต่อสำเร็จแล้ว

## ขั้นตอนที่ 3 — ตั้งค่า config

```bash
cp config.example.yaml config.yaml
```

เปิด `config.yaml` แล้วใส่ `apps_url` เป็น Cloudflare Worker URL เดียวกับที่ตั้งไว้ในเว็บแอป
`bengen-mobile` (ช่อง "Backend URL (Worker)" ในหน้า Settings)

## ขั้นตอนที่ 4 — การคาลิเบรต (สำคัญที่สุด)

ไฟล์ `bengen_auto_post.py` มีฟังก์ชันหลายตัวที่ทำเครื่องหมาย `TODO [คาลิเบรต]` ไว้ — นั่นคือจุดที่
ต้องหาตำแหน่งปุ่ม/ชื่อ element จริงจาก**แอป Shopee ที่ติดตั้งอยู่บนเครื่องคุณ** มาแทนที่ selector
ตัวอย่างในโค้ด

### เครื่องมือช่วยคาลิเบรต: weditor

```bash
pip install weditor
python -m weditor
```

จะเปิดหน้าเว็บ (ปกติที่ `http://localhost:17310`) ให้เลือกอุปกรณ์ของคุณ แล้วจะเห็นภาพหน้าจอ
โทรศัพท์แบบเรียลไทม์ — **คลิกที่ปุ่มไหนบนภาพ จะโชว์ resourceId / text / description ของปุ่มนั้น
ให้ทันที** ใช้ค่านี้ไปแทนที่ใน `bengen_auto_post.py`

### ขั้นตอนคาลิเบรตแนะนำ (ทำทีละฟังก์ชัน)

1. เปิดแอป Shopee บนมือถือด้วยมือ ไปที่หน้า "สร้างวิดีโอ" เอง พร้อม weditor เปิดคู่กัน
2. คลิกปุ่มแต่ละปุ่มตามลำดับที่จะกดจริง (ไอคอน Shopee Video → สร้างวิดีโอ → เลือกจากแกลเลอรี่ →
   ถัดไป → ช่องแคปชั่น → ปุ่มแนบสินค้า → ช่องค้นหาสินค้า → ผลลัพธ์แรก → เสร็จสิ้น → โพสต์/บันทึกร่าง)
   จดค่า resourceId หรือ text ของแต่ละปุ่มไว้
3. แทนที่ค่าตัวอย่างในฟังก์ชันที่ตรงกันในไฟล์ `bengen_auto_post.py`:
   - `open_shopee_video_composer()`
   - `select_video_from_gallery()`
   - `fill_caption()`
   - `attach_product()`
   - `finalize_post()`
4. ทดสอบทีละฟังก์ชันด้วยการรัน `--dry-run` ก่อน (ข้ามการควบคุมโทรศัพท์ เช็คแค่ว่าดึง/ดาวน์โหลด
   ข้อมูลจาก Sheets ได้ถูกต้อง) แล้วค่อยลองแบบเต็มกับวิดีโอทดสอบ 1 คลิป

> ติดตรงไหน ส่งผลลัพธ์จาก weditor (ชื่อ resourceId/text ของปุ่มที่เจอ) มาให้ผมช่วยเติมโค้ดส่วน
> ที่เหลือให้ต่อได้เลยครับ

## วิธีใช้งาน

**โพสต์เอง (manual)** — เลือก content id จาก Sheet มาโพสต์ทันที:

```bash
python bengen_auto_post.py --mode manual --content-id <CONTENT_ID>
```

**บันทึกเป็นร่างแทนโพสต์จริง** — เติม `--draft`:

```bash
python bengen_auto_post.py --mode manual --content-id <CONTENT_ID> --draft
```

**ตั้งเวลาโพสต์อัตโนมัติ** — ตั้งค่าที่ Sheet `Content` ของ row นั้นก่อน:
   - คอลัมน์ `postMode` = `scheduled`
   - คอลัมน์ `scheduledAt` = เวลาที่ต้องการให้โพสต์ (รูปแบบ ISO เช่น `2026-09-25T09:00:00Z`)

   จากนั้นตั้ง Task Scheduler (Windows) หรือ cron (Mac/Linux) ให้รันคำสั่งนี้ทุก 15-30 นาที:

```bash
python bengen_auto_post.py --mode scheduled
```

   สคริปต์จะเช็คเองว่ามีรายการไหนถึงเวลาโพสต์แล้วบ้าง แล้วโพสต์ให้อัตโนมัติทีละรายการ
   (เว้นระยะระหว่างรายการตาม `min_gap_seconds`/`max_gap_seconds` ใน config)

**ทดสอบโดยไม่ยุ่งกับโทรศัพท์จริง** — เติม `--dry-run` ที่โหมดไหนก็ได้ (เช็คแค่การดึง/ดาวน์โหลดข้อมูล)

## ข้อควรระวัง

- นี่คือการโพสต์เนื้อหาเข้าบัญชี Shopee จริงของคุณแบบอัตโนมัติ ต่างจากแค่การดึงข้อมูลอ่านอย่างเดียว
  — ควรเว้นระยะเวลาสมเหตุสมผล ไม่โพสต์รัวๆ หรือตรงเวลาเป๊ะทุกครั้ง
- UI ของแอป Shopee อาจเปลี่ยนได้ตลอดเวลาที่มีอัปเดตแอปใหม่ ถ้าสคริปต์เริ่มพัง (หา element ไม่เจอ)
  ให้กลับไปคาลิเบรตใหม่ตามขั้นตอนที่ 4
- ถ้าโพสต์พังกลางทาง (เช่น หา element ไม่เจอ, ต่อโทรศัพท์หลุด) สคริปต์จะ**ไม่**เรียก `markPosted`
  ให้ — ข้อมูลใน Sheet จะไม่เพี้ยน แต่ต้องเข้าไปเช็คในแอป Shopee เองว่าโพสต์ค้างอยู่หรือเปล่า
  ก่อนสั่งรันซ้ำ (กันโพสต์ซ้ำ 2 รอบ)
