# BenGen AutoPost — โพสต์ Shopee Video อัตโนมัติ

โพสต์วิดีโอสินค้าจากระบบ BenGen Affiliate ขึ้น **Shopee Video** ตามเวลาที่ตั้งไว้ในเว็บแอป `bengen-mobile`
โดยควบคุมแอป Shopee บนมือถือ Android จริงผ่าน USB (ADB + uiautomator2, ไม่ต้อง root)

⚠️ Shopee ไม่มี API ให้อัปโหลดวิดีโอ ระบบนี้จึง "กดแอปแทนคน" — ปุ่มถูกคาลิเบรตไว้กับ
**Honor 70 (1080×2400) + Shopee 3.81.32** ถ้าแอปอัปเดต Agent จะหยุดโพสต์และเตือนให้คาลิเบรตใหม่

---

## ภาพรวม

```
┌─ มือถือคุณ: เว็บแอป bengen-mobile ─┐        ┌─ Google Sheet (ผ่าน Cloudflare Worker) ─┐
│ แท็บ 🤖 AutoPost                   │ ←────→ │ Content         : สถานะแต่ละคลิป        │
│ • ตั้งเวลา / กระจายเวลา             │        │ AutoPostStatus  : สถานะเครื่องโพสต์     │
│ • ตรวจเครื่อง / สวิตช์หยุดโพสต์     │        └───────────────────┬─────────────────────┘
│ • จัดการคลิปที่ "ต้องดูแล"          │                            │
└─────────────────────────────────────┘        ┌─ คอม: bengen_agent.py (รันค้าง) ───────┐
                                               │ • รายงานสถานะเครื่องทุก 30 วิ            │
                                               │ • ตอบ "ตรวจตอนนี้" / อ่านสวิตช์ทุก 15 วิ  │──USB──▶ มือถือโพสต์
                                               │ • โพสต์คลิปที่ถึงเวลา ทีละคลิป            │
                                               └─────────────────────────────────────────┘
```

- เว็บแอป**สั่งคอมตรงๆ ไม่ได้** ทุกคำสั่งเขียนลง Sheet แล้ว Agent มาอ่าน (ช้าสุด ~15–30 วิ)
- คอมต้องเปิดอยู่ + ต่อมือถือ ระบบถึงจะโพสต์ได้ ถ้าคอมปิด คลิปจะรอ และถ้าเลยเวลาเกิน 2 ชม. จะไม่โพสต์เอง

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `bengen_agent.py` | **Agent** — โปรแกรมที่รันค้างบนคอม (ตรวจเครื่อง, รายงานสถานะ, โพสต์ตามเวลา) |
| `bengen_auto_post.py` | ขั้นตอนกดแอป Shopee (คาลิเบรตแล้ว) + คำสั่งโพสต์ทีละคลิปแบบ manual |

| `Code.gs` | Apps Script ฝั่ง Sheet (สำเนาอ้างอิง) |
| `logs/agent.log` | log ของ Agent (สร้างเอง, ไม่เข้า git) |

## ติดตั้งครั้งแรก

### 1. มือถือ
1. ตั้งค่า → เกี่ยวกับโทรศัพท์ → กด "หมายเลขบิลด์" 7 ครั้ง
2. ตัวเลือกสำหรับนักพัฒนา → เปิด **USB debugging** และ **Stay awake** (จอไม่ดับตอนชาร์จ)
3. เสียบสาย USB (สายที่ส่งข้อมูลได้ ไม่ใช่สายชาร์จอย่างเดียว) → กด **Allow** บน popup
4. Login แอป Shopee ไว้ และใช้ที่ชาร์จที่จ่ายไฟพอ (ชาร์จจาก USB โน้ตบุ๊กอาจไม่ทันตอนเปิดจอค้าง)

### 2. คอม
```powershell
winget install Python.Python.3.12
winget install Google.PlatformTools
pip install -r requirements.txt
python -m uiautomator2 init          # ลง agent เล็กๆ ในมือถือ (ครั้งเดียว)
```
- ตั้ง Windows ไม่ให้ Sleep ตอนเสียบปลั๊ก: Settings → System → Power → *When plugged in, sleep after* = **Never**
  (หรือ `powercfg /change standby-timeout-ac 0`)

### 3. config
```powershell
copy config.example.yaml config.yaml
```
แก้ใน `config.yaml` อย่างน้อย:
- `apps_url` — Cloudflare Worker URL (อันเดียวกับช่อง "Backend URL (Worker)" ในเว็บแอป)
- `adb_dir` — โฟลเดอร์ที่มี `adb.exe` (ถ้าติดตั้งด้วย winget อยู่ใต้ `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Google.PlatformTools_...\platform-tools`)
- `posting_enabled: true` — สวิตช์หลักบนคอม (false = Agent ไม่โพสต์เลย ไม่ว่าเว็บจะสั่งอะไร)

### 4. Google Sheet (Worker สร้างชีต/คอลัมน์ใหม่เองไม่ได้ — ต้องเพิ่มเองครั้งเดียว)
**ชีต `Content`** เพิ่มหัวคอลัมน์ (ชื่อต้องตรงเป๊ะ ระวังช่องว่างท้ายคำ):
`postMode` · `scheduledAt` · `postError` · `postAttempts` · `postStartedAt`

**สร้างชีตใหม่ `AutoPostStatus`:**

| | A | B | C | D | E |
|---|---|---|---|---|---|
| 1 | id | status | checkRequestedAt | updatedAt | postingPaused |
| 2 | host | | | | |

### 5. เปิด Agent อัตโนมัติ
ดับเบิลคลิก **`install_agent_task.cmd`** → ต้องขึ้น `สถานะ: Running`
- เปิดเองตอนล็อกอิน Windows + watchdog ทุก 1 นาที (Agent ตาย → เปิดใหม่เองภายใน 1 นาที)
- รันแบบไม่มีหน้าต่าง ดู log ที่ `logs\agent.log`
- ถ้ามี Agent ที่เปิดเองในหน้าต่าง PowerShell ค้างอยู่ ให้ `Ctrl+C` ก่อน สคริปต์จะไม่ปิดให้เอง

ทดสอบ Agent แบบรอบเดียว (ไม่โพสต์): `python bengen_agent.py --once`

## ใช้งานประจำวัน (เว็บแอป → แท็บ 🤖 AutoPost)

**แถบสถานะด้านบน**
| สี | ความหมาย |
|---|---|
| 🟢 พร้อมโพสต์ | Agent ออนไลน์ มือถือพร้อม |
| 🟣 กำลังโพสต์ | กำลังโพสต์คลิปหนึ่งอยู่ |
| 🟡 รอเครื่อง | เช่น จอล็อก / ไม่พบมือถือ — คลิปจะรอ ไม่นับว่าพัง |
| ⚪ หยุดโพสต์อยู่ | ปิดสวิตช์ในเว็บ หรือ `posting_enabled: false` บนคอม |
| 🔴 คอมออฟไลน์ | Agent ไม่รายงานมาเกิน 2 นาที (คอมปิด/หลับ) |

แตะแถบ → ดูรายละเอียด + ปุ่ม **🔍 ตรวจตอนนี้** / สวิตช์ **โพสต์อัตโนมัติ** อยู่ขวาของแถบ

**ตั้งเวลา:** เลือกคลิปในกลุ่ม "พร้อมตั้งเวลา" → เลือกเวลา (เวลาไทย) → 💾 ระบบจะตรวจเครื่องก่อนบันทึก
หรือโหมดเลือกหลายคลิป → **กระจายเวลา**

**กลุ่ม "ต้องดูแล"**
| ป้าย | เกิดจาก | ต้องทำ |
|---|---|---|
| 🔍 ต้องตรวจสอบ | Agent หยุดกลางทาง/พังหลังกดโพสต์ — ไม่รู้ว่าคลิปขึ้นหรือยัง | เปิดแอป Shopee เช็ค แล้วกด **✅ ขึ้นแล้ว** หรือ **🔁 ยังไม่ขึ้น ลองใหม่** |
| ⏰ เลยเวลา | เลยเวลาที่ตั้งเกิน 2 ชม. (คอมปิด/เครื่องไม่พร้อม) | ตั้งเวลาใหม่ หรือยกเลิก |
| ❌ ล้มเหลว | พังก่อนกดโพสต์ครบ 3 ครั้ง | ดูสาเหตุ แล้วลองใหม่/ตั้งเวลาใหม่ |

## กติกาความปลอดภัยของ Agent

1. **ไม่โพสต์ซ้ำ** — ก่อนเริ่มจะ "จอง" คลิปด้วย `postStartedAt` ถ้า Agent ตายหรือพังหลังกดโพสต์
   คลิปจะไปอยู่ "ต้องตรวจสอบ" และ**ไม่ลองใหม่เอง**
2. **พังก่อนกดโพสต์** (หาปุ่มไม่เจอ ฯลฯ) → ปิดแอป Shopee ทิ้ง (ละทิ้งวิดีโอค้าง) นับ `postAttempts`
   ลองใหม่หลัง 10 นาที ได้อีก 2 ครั้ง
3. **เช็คเครื่องก่อนทุกคลิป** — ไม่พร้อมคือรอ ไม่นับว่าพัง
4. **อ่านแถวล่าสุดอีกรอบก่อนเริ่ม** — ยกเลิกจากเว็บระหว่างรอก็ไม่โพสต์
5. **เวอร์ชัน Shopee ไม่ตรงกับที่คาลิเบรต** → หยุดโพสต์
6. **รออัปโหลดเสร็จจริง** ("กำลังอัปโหลด…" → "อัปโหลดสำเร็จ") ก่อนบันทึก `postedAt`
7. จำกัด `daily_limit` คลิป/วัน (เวลาไทย), เว้นช่วงสุ่ม `min_gap_seconds`–`max_gap_seconds` ระหว่างคลิป
8. ลบวิดีโอออกจากมือถือ (ไฟล์ + คลังภาพ) และจากคอมหลังโพสต์เสร็จ

⚠️ นี่คือการโพสต์เข้าบัญชีจริง โพสต์ถี่มากๆ ทุกวันเสี่ยงถูกมองเป็นสแปม ควรเพิ่มจำนวนทีละน้อยและดูสถานะบัญชี

## ค่าตั้งค่า (`config.yaml`)

| key | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `apps_url` | – | Worker URL |
| `temp_dir` | `./temp_videos` | ที่พักวิดีโอก่อนส่งเข้ามือถือ |
| `min_gap_seconds` / `max_gap_seconds` | 120 / 300 | เว้นช่วงสุ่มระหว่างคลิป |
| `ai_label` | true | เปิดสวิตช์ "ครีเอเตอร์เพิ่มป้ายกำกับ AI" ทุกโพสต์ |
| `adb_dir` | – | โฟลเดอร์ `adb.exe` |
| `calibrated_shopee_version` | `3.81.32` | เวอร์ชันแอปที่คาลิเบรตไว้ |
| `heartbeat_seconds` | 30 | รายงานสถานะทุกกี่วิ |
| `poll_seconds` | 15 | เช็คคำสั่งจากเว็บทุกกี่วิ |
| `queue_seconds` | 60 | อ่านคิว Content ทุกกี่วิ |
| `battery_warn_percent` | 20 | เตือนแบตต่ำ (ไม่ชาร์จ = หยุดโพสต์) |
| `overdue_max_minutes` | 120 | เลยเวลาเกินนี้ไม่โพสต์เอง |
| `daily_limit` | 70 | สูงสุดกี่คลิป/วัน |
| `retry_max` / `retry_delay_minutes` | 2 / 10 | ลองใหม่เมื่อพังก่อนกดโพสต์ |
| `posting_enabled` | false | สวิตช์หลักบนคอม |
| `capture_after_post` | false | เก็บภาพหน้าจอหลังกดโพสต์ไว้ที่ `logs/after_post/` (ใช้ตอนคาลิเบรต) |

แก้ config แล้วต้องรีสตาร์ท Agent: `uninstall_agent_task.cmd` → `install_agent_task.cmd`

## โพสต์ทีละคลิปเอง (ไม่ผ่าน Agent)

```powershell
python bengen_auto_post.py --mode manual --content-id <CONTENT_ID> --draft   # บันทึกเป็นแบบร่าง
python bengen_auto_post.py --mode manual --content-id <CONTENT_ID>           # โพสต์จริง
python bengen_auto_post.py --mode manual --content-id <CONTENT_ID> --dry-run # แค่ดึงข้อมูล/ดาวน์โหลด
```
ถ้า Agent รันอยู่ด้วย ให้หยุดสวิตช์โพสต์ในเว็บก่อน กันสองโปรแกรมแย่งมือถือ

## เมื่อ Shopee อัปเดตแอป (คาลิเบรตใหม่)

Agent จะแจ้ง "Shopee อัปเดตเป็น x.y.z — ต้องคาลิเบรตใหม่" และหยุดโพสต์
1. เปิดแอปไปทีละหน้าตามขั้นตอนโพสต์ แล้วดู resourceId/text ของปุ่ม (`pip install weditor` → `python -m weditor`)
2. แก้ selector ในฟังก์ชันของ `bengen_auto_post.py`:
   `open_shopee_video_composer` → `select_video_from_gallery` → `fill_caption` → `attach_product` →
   `enable_ai_label` → `finalize_post` → `wait_upload_done`
   (หน้าเพิ่มแคปชั่นอยู่ใน plugin — ค่า `PUBLISH_PLUGIN` อาจเปลี่ยนเลข)
3. ทดสอบด้วย `--draft` ก่อน แล้วค่อยแก้ `calibrated_shopee_version` ใน config และรีสตาร์ท Agent

จุดที่ผูกกับหน้าจอ 1080×2400: ไอคอน 🔗 ในหน้าเพิ่มสินค้ากดตามตำแหน่ง (`d.click(0.922, 0.065)`)

## แก้ปัญหา

| อาการ | ลองทำ |
|---|---|
| แถบ 🔴 คอมออฟไลน์ | คอมเปิดอยู่ไหม / หลับไหม / Task `BenGen AutoPost Agent` ใน Task Scheduler ยัง Ready/Running ไหม |
| "ไม่พบมือถือ" | เปลี่ยนสาย/ช่อง USB, ตั้งโหมด USB เป็นถ่ายโอนไฟล์, เช็ค `adb devices` |
| "มือถือยังไม่อนุญาต USB debugging" | ปลดล็อกจอแล้วกด Allow |
| "จอมือถือล็อกอยู่" | ปลดล็อก + เปิด Stay awake |
| คลิปค้าง "ต้องตรวจสอบ" | เช็คในแอป Shopee → ขึ้นแล้ว / ลองใหม่ |
| อยากดูว่าเกิดอะไรขึ้น | `logs\agent.log` (บันทึกทุกครั้งที่สถานะเครื่องเปลี่ยน, เริ่ม/จบ/พังแต่ละคลิป) |
| กดตรวจตอนนี้แล้ว timeout | Agent ไม่ได้รัน → ดับเบิลคลิก `install_agent_task.cmd` |
