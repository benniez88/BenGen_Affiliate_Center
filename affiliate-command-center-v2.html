📊 Google Sheets Sync

ℹ️ ยังไม่ได้เชื่อมต่อ Google Sheets — ดู วิธีตั้งค่า ด้านล่าง
📖 วิธีตั้งค่า Google Sheets (คลิกเพื่อขยาย)
1️⃣สร้าง Google Sheets ใหม่ → Extensions → Apps Script
2️⃣วางโค้ดจากไฟล์ Code.gs ที่แนบมา → Save
3️⃣Deploy → New Deployment → Web App → Execute as: Me → Access: Anyone
4️⃣Copy URL ที่ได้มาวางในช่องด้านบน → กด "ทดสอบ"
⚠️ครั้งแรกจะมีขอ Permission — กด Allow เพื่ออนุญาต
🔑 ตั้งค่า Shopee API Keys ใน Script Properties (ปลอดภัย)
5️⃣ใน Apps Script → Project Settings → Script Properties → เพิ่ม:
SHOPEE_APP_ID = your_app_id
SHOPEE_SECRET = your_secret_key
💡Secret Key จะอยู่ใน Script Properties เท่านั้น — ไม่หลุดมาที่ Browser เด็ดขาด

🔑 API Keys (เก็บเฉพาะในเครื่อง — ไม่ Sync ขึ้น Sheets)

ยังไม่มี Key?
🔑 สร้าง Key ฟรีที่ AI Studio →
💡 สร้าง Key จาก aistudio.google.com/apikey → เลือก "Create new project" (ไม่ใช่ Project ที่มี Billing) → ฟรี 1,500 requests/วัน
